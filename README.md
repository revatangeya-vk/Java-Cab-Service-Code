# Java Cab Service Code

## Project Description

A Java console-based application for managing cab services and calculating fares based on the selected cab type and travel distance.

## Features

- Cab selection: Mini, Sedan, and SUV
- Distance-based fare calculation
- 10% discount for distances above 20 km
- Exception handling for invalid choices
- Uses Object-Oriented Programming concepts
- Displays the selected cab and total fare

## Technologies Used

- Java
- Object-Oriented Programming
- Scanner for user input

## Cab Fare

| Cab Type | Fare per km |
|----------|-------------|
| Mini | Rs.15 |
| Sedan | Rs.20 |
| SUV | Rs.25 |

## How It Works

The user selects a cab type and enters the travel distance. The program calculates the total fare based on the selected cab. A 10% discount is applied when the distance is more than 20 km.
